# Story 1.4: 左侧菜单入口 + 国际化

Status: done

## Story

As a **管理员**,
I want **在左侧菜单看到"数据源配置"入口，且页面文案支持中英文**,
so that **我可以快速进入管理页面，界面语言与平台一致**。

## Acceptance Criteria

1. **菜单展示（管理员）**
   - Given 管理员登录平台
   - When 查看左侧菜单
   - Then 显示"数据源配置"菜单项，风格与现有菜单项一致
   - And 点击后跳转到 `/chat/datasources` 页面

2. **菜单隐藏（非管理员）**
   - Given 非管理员用户登录平台
   - When 查看左侧菜单
   - Then 不显示"数据源配置"菜单项

3. **中文国际化**
   - Given 系统语言设置为中文
   - When 查看数据源管理页面
   - Then 所有文案显示中文

4. **英文国际化**
   - Given 系统语言设置为英文
   - When 查看数据源管理页面
   - Then 所有文案显示英文
